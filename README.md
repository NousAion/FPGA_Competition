# FPGA Competition — 高云选题二

## 作品简介

本作品面向高云选题二，目标是实现一台基于 Tang Mega 138K C 版的实时多音色合成电子乐器。
音频合成核心固定使用 `GW5AST-138C` FPGA 逻辑，音频生成通路不依赖 MCU、软核处理器、
上位机或预录 PCM；每个输出采样由 FPGA 根据当前演奏控制量逐样本生成。板上的下载器或
辅助控制器不属于音频合成通路。

系统采用“交互事件 -> 声部管理 -> 振荡器/波表/ADSR -> 混音/效果器 -> I2S -> DAC”的分层架构。
第一阶段以钢琴式按键或实体按键作为主要交互输入，先完成固定测试音、单声部和至少 4 声部
的稳定闭环；按键负责音符选择与触发，交互接口再逐步加入力度、滑音、颤音和音色选择等参数。
当前硬件目标是 12 键主键盘，配合压力检测和连续控制器；APDS-9960 可作为扩展交互器件，
通过 FPGA I2C 读取手势、接近度或环境光参数，用于滑音、颤音、音色或效果深度控制。
APDS-9960 不替代实体按键，也不直接提供压力值；具体接线、寄存器配置和扫描时序要在实物验证后确认。

音源以加法合成为主、FM 调频为扩展方向。一个可计数的独立振荡器必须具备独立的相位累加器、
频率控制和包络控制；多个声部在 FPGA 内部混音后，通过 Tang Mega 138K Dock 的 I2S 音频链路
输出到 DAC、耳机或功放。

项目目标分阶段推进：基础闭环为至少 2 个独立演奏控制维度、至少 4 声部、ADSR、混音、I2S
输出以及不超过 10 ms 的控制到音频延迟；主线扩展为至少 32 个独立发声单元、至少 3 维表情、
至少 2 种可切换音色和至少一种 FPGA 内可旁路效果器（延迟、混响或合唱）。资源和时序允许时，
冲刺目标为 4 声部 × 32 个独立合成分量，
即最多 128 个可计数振荡器；在 48 kHz 输出采样率下，对应理论吞吐量为
`128 × 48 kHz = 6.144 M osc·Hz`。同时尝试 5 ms 以内的确定性延迟和 HDMI/LED/波形等实时反馈。
这些数量和交互功能在完成相应仿真、综合、上板和现场测试前均视为设计目标，不作为已完成声明。

当前目标平台为 **Tang Mega 138K（普通 PG484 SOM）+ Tang Mega 138K Dock（NEO Dock 系列底板）**。已确认 SOM 为 C 版，
工程器件固定为 `GW5AST-138C / GW5AST-LV138PG484AC1/I0`；138K Pro（FPG676A）不属于当前目标。

项目目标分层如下：

- 必须完成：选题二全部基础要求；
- 主线扩展：扩展 1（≥32 个独立复音/合成分量）和扩展 2（≥3 维表情、≥2 种音色、FPGA 内效果器）；
- 冲刺扩展：扩展 3（≤5 ms 确定性延迟与实时视听反馈）；
- 风险兜底：若进度受限，至少保证扩展 1 或扩展 2 中一项完整、可现场验证。

## 目录

- `src/`：现有 Gowin 工程入口与旧例程
- `rtl/`：按功能划分的可复用 RTL
- `tb/`：新模块仿真测试
- `sim_tb/`：历史例程仿真，暂保留
- `constraints/`：按具体开发板维护的约束
- `docs/`：设计、接口、测试和报告
- `scripts/`：构建、仿真和报告脚本
- `ip/`：明确登记版本的 Gowin IP

## 开发原则

音频主链路必须由 FPGA HDL 逐样本实时生成；禁止把 AE350、软核、MCU 或上位机作为音频合成核心。
所有时钟域、定点位宽、采样率和延迟预算以 `docs/project-analysis.md` 为单一设计锚点。
