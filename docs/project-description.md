# 作品简介

本作品以高云 Tang Mega 138K C 版（GW5AST-138C）为唯一计算核心，不使用任何 MCU、软核或第三方音频 IP，目标是做成一台可以真正演奏的电子乐器：支持多声部并发与和弦识别，触键即触发带完整包络的乐音，力度、滑音、颤音可实时调控，能连续完整演奏而不丢音、不误触发。

音源采用加法合成为主、FM 调频为辅的混合架构，每一路发声分量均由独立的相位累加器、频率调控字与幅度包络构成，为可独立计数的完整振荡器；引擎支持分量—声部动态配比，高密度模式下 4 声部 × 32 分量共 128 路独立振荡器并发，峰值吞吐量达 128 × 48 kHz ≈ 6.14 M osc·Hz，每声部具备独立 ADSR 包络，支持单音实时变调、多声部实时混音、至少两种可切换音色，并在 FPGA 内实现延迟、混响或合唱等数字效果器，端到端延迟控制在 5 ms 以内且确定性无抖动。

交互端自主设计 12 键位钢琴式实体按键演奏面板，配合压力检测与旋转编码器构成选音与和弦、力度感应、表情调控三个独立可控维度，电容触控作为可选辅助交互方式；音频通过 I2S 接口输出至 DAC、耳机或功放，板载 HDMI 实时显示活跃振荡器数、采样率与吞吐量指标及波形。

所有发声均由 FPGA 依据实时演奏指令逐音、逐样本生成，不含任何预录 PCM 音频回放。
