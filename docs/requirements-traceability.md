# 选题二目标与验收矩阵

## 目标分层

本项目锁定高云选题二，主板为 Tang Mega 138K + Tang Mega 138K Dock（NEO Dock 系列底板）。

| 层级 | 目标 | 交付判据 |
|---|---|---|
| 基础 1 | 至少 2 个独立演奏控制维度 | 可重复采集并解析音高/触发与力度或表情 |
| 基础 2 | FPGA HDL 逐样本实时合成 | 音频主链路无 CPU/上位机/预录 PCM，控制到输出 ≤10 ms |
| 基础 3 | ≥4 复音 | 至少 4 个独立声部同时发声，含 ADSR、混音和 I2S 输出 |
| 扩展 1（主线） | ≥32 独立复音或合成分量 | 测试模式输出不同频率，频谱和 RTL 能证明独立振荡器数量 |
| 扩展 2（主线） | ≥3 维表情、≥2 音色、FPGA 内效果器 | 将 2a/2b/2c 分开验收：表情、音色、至少一种效果器（目标两种） |
| 扩展 3（冲刺） | ≤5 ms 无抖动与视听反馈 | 计数器测得固定延迟，并完成 LED/波形/频谱至少一种反馈 |
| 扩展 4 | 脱机曲目/蓝牙 App 联动 | 暂不纳入主线，基础与扩展 1/2 稳定后再评估 |

“至少一项”是项目进度兜底，不是题目规定的扩展门槛。计划上按扩展 1+2 双主线设计，若时间不足，优先保住其中一项完整闭环。

## 证据要求

每个已完成目标都要留下：

1. RTL 模块与接口说明；
2. 仿真波形或测试日志；
3. 板上录音/频谱/延迟测量结果；
4. 综合资源、时序和版本信息。

AE350 只可作为非音频辅助控制的后备方案；不得替代 FPGA HDL 音频生成路径。
