# 选题二目标与验收矩阵

## 目标分层

本项目锁定高云选题二，主板为 Tang Mega 138K + Tang Mega 138K Dock（NEO Dock 系列底板）。

| 层级 | 目标 | 交付判据 |
|---|---|---|
| 基础 1 | 至少 2 个独立演奏控制维度 | 可重复采集并解析音高/触发与力度或表情 |
| 基础 2 | FPGA HDL 逐样本实时合成 | 音频主链路无 CPU/上位机/预录 PCM，控制到输出 ≤10 ms |
| 基础 3 | ≥4 复音 | 至少 4 个独立声部同时发声，含 ADSR、混音和 I2S 输出 |
| 扩展 1（主线） | ≥32 独立复音或合成分量 | 测试模式输出不同频率，频谱和 RTL 能证明独立振荡器数量；项目冲刺目标为 4 声部 × 32 分量，共 128 个可计数振荡器 |
| 扩展 2（主线） | ≥3 维表情、≥2 种可切换音色、FPGA 内效果器 | 将 2a/2b/2c 分开验收：表情、音色、至少一种可旁路效果器（目标两种） |
| 扩展 3（冲刺） | ≤5 ms 无抖动与视听反馈 | 计数器测得固定延迟，并完成 LED/波形/频谱至少一种反馈 |
| 扩展 4 | 脱机曲目/蓝牙 App 联动 | 暂不纳入主线，基础与扩展 1/2 稳定后再评估 |

“至少一项”是项目进度兜底，不是题目规定的扩展门槛。计划上按扩展 1+2 双主线设计，若时间不足，优先保住其中一项完整闭环。

## 官方现场统计口径

扩展 1 的“独立发声单元”不能只按波表查表次数计算。官方口径要求每个可计数单元至少包含：

- 独立相位累加器；
- 独立频率控制；
- 独立包络控制。

单个波表采样查表不因包含多个谐波而重复计数；加法合成按独立运算分量统计，FM 按调制运算器统计，物理建模按并行弦/模态单元统计。现场测试应进入专用测试模式，同时输出不同频率，使频谱仪或采样记录能够观察到相应谱峰，并用 RTL 结构和综合报告佐证单元数量。

扩展 2 对外只在 2a、2b、2c 均完成时宣称完成：

- 2a：至少 3 个独立表情维度，并能在演奏中分别改变参数；
- 2b：至少 2 种可切换音色；
- 2c：FPGA 内部至少一种可旁路、可测量的延迟/混响/合唱效果器。

当前交互方案目标为 12 键钢琴式/实体按键、压力检测和连续控制器；APDS-9960 可作为 I2C
手势/接近度扩展输入，电容触控作为可选辅助输入。它们对应的计划控制维度为：

- 音符选择、和弦与触发；
- 力度/音量；
- 连续表情参数，如滑音、颤音或音色参数。

扩展 2 还必须明确两种可切换音色，以及至少一种在 FPGA 内实现、可旁路、可测量的延迟/混响/合唱效果器。
三类硬件输入都必须在实物上完成扫描、标定和重复性验证后，才可在验收材料中标记为已实现。

## 证据要求

每个已完成目标都要留下：

1. RTL 模块与接口说明；
2. 仿真波形或测试日志；
3. 板上录音/频谱/延迟测量结果；
4. 综合资源、时序和版本信息。

AE350 只可作为非音频辅助控制的后备方案；不得替代 FPGA HDL 音频生成路径。
